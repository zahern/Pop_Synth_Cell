\subsection{Composition control in expansion}
\label{sec:expansion_composition}
The mixed-integer program in Section~\ref{sec:mip_expansion_formulation}
optimises coverage and marginal composition jointly, but only over the support
set it selects. To expose the distinction, a full-menu build appends the
remaining candidate menu after the solve; those appended records are not part of
the admission vector, are not in the deviation terms and are not subject to the
composition tie-break. The result is a pool that is cell-complete but
compositionally skewed, with a surplus of size-7 households and \texttt{mtwp}
code 17. Table~\ref{tab:expansion_composition} reports the base pool, that
build and the controlled variants.

Two composition-controlled variants were built from the same shards, without
rerunning the MIP. The \emph{coverage-only} variant keeps the selected support
set and drops the appended menu. The \emph{composition-aware} variant keeps the
base pool, the selected set and only those appended households that are neither
size 7 nor contain \texttt{mtwp} code 17. The implementation also exposes a
composition-weight multiplier, optional caps and a minimum-admitted-household
bound; hard caps alone can starve coverage, so the reported variants use the two
filters. Table~\ref{tab:expansion_composition} reports their composition and
fitted RSSZ.

A further build increased the donor menu rather than the shell count.
Table~\ref{tab:expansion_composition} shows that it is dominated by verbatim
census households carrying \texttt{mtwp} code 17, and that the composition
filter keeps only a small fraction of the appended records. The filtered pool is
only marginally larger than the 300-donor composition-aware pool. The build is
therefore reported as a negative result: it does not deliver a substantially
larger clean pool and is not used to claim a larger-pool effect.

The fitted result in Table~\ref{tab:expansion_composition} identifies the
mechanism. The composition-aware pool removes the SA penalty and lowers the IPU
mean; the coverage-only pool recovers most of the penalty but keeps fewer
candidates at the same composition. The difference between the two controlled
variants is therefore pool size, not composition: both remove the appended-menu
skew.
